- 산출물: `golden_master_expected.txt`, 생성 스크립트, 설계 문서

**Cursor**

- `tests/golden_master_expected.txt` — 실제 출력 기반 5 시나리오
- `docs/Golden_Master_Approve_Pattern.md` — approve 패턴 설계
- `pytest.ini` — `pythonpath = src scripts`
- `tests/conftest.py` — `--approve-golden` 옵션

**결정 사항**

- 출력 캡처: **Result DTO serialize** (stdout 아님)
- 예시 템플릿 `[3,3,1,4,4,6]` 은 해당 격자에서 수학적으로 성립하지 않아 **실제 솔버 출력**으로 기준선 확정
