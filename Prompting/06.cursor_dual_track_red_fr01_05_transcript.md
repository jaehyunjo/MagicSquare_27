**Track A — Boundary / UI**

1. matrix=null → E003  
2. size ≠ 4×4 → E001  
3. 빈칸 ≠ 2 → E002  
4. 값 범위 위반 → E004  
5. non-zero 중복 → E005  
6. 성공 시 길이 6 (U-OUT-01)  
7. 좌표 1-index [1,4] (U-OUT-02)  
8. invalid 시 execute call_count == 0 (U-FLOW-02)

**Track B — Domain / Logic**

- `find_blank_coords` — G1 → (2,2), (3,3) (D-LOC-01, I6)
- `find_not_exist_nums` — G1 → {7,10} (D-MIS-01, I7, I11)
- `is_magic_square` — G0 true; 행/열/대각/집합/0포함 반례 분리 (D-VAL-01~06, I1~I5)
