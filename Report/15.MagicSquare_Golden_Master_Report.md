## 2. Approve Pattern

```text
baseline 없음  →  capture_all_scenarios() 로 자동 생성
baseline 있음  →  open(expected).read() vs actual 비교
불일치        →  --- expected / +++ actual / @@ hunks @@  후 FAIL
의도적 갱신   →  pytest -m golden_master --approve-golden
              또는  python scripts/generate_golden_master.py
```

| 모듈 | 역할 |
|------|------|
| `scripts/golden_master.py` | DTO 직렬화, capture, parse, unified diff, approve |
| `scripts/generate_golden_master.py` | 기준 파일 생성 CLI |
| `tests/conftest.py` | `--approve-golden` 옵션 등록 |

## 4. Solver Strategy (캡처 대상)

` solve_two_step_traced()` (`scripts/golden_master.py`):

1. `_parse_partial_grid()` — `demo_solver` 입력 검증
2. 누락 수 `{low, high}`에 대해:
   - **small-first**: `low → blank₁`, `high → blank₂`
   - **reverse**: `high → blank₁`, `low → blank₂`
3. `_is_complete_magic()` (M=34) 통과 시 int[6] 반환
4. 둘 다 실패 → `NO_VALID_MAGIC_SQUARE`

blank 순서는 row-major 탐지 순서를 따른다.
