## 1. RED — 이해 요약

RED는 **구현보다 먼저 실패하는 테스트를 고정**하는 단계다.

- assert가 있고 `pytest` 실행 시 **의도적 실패**가 RED 완료 조건이다.
- 실패 원인: `NotImplementedError`, `pytest.fail("RED: ...")` — 정상.
- RED에서 **`src/` 동작 구현 금지** — 스텁만 허용.
- 커밋 접두사: `test:`

### 1.1 트랙 비교

| 트랙 | 의미 | 테스트 | RED 형태 |
|------|------|--------|----------|
| **ECB** | AC-FR-01-01 / TC-011 | `tests/unit/boundary/test_ac_fr_01_01_invalid_size.py` | Full RED (assert) |
| **Dual-Track** | FR-01~05, E003/E001… | `tests/boundary/`, `tests/entity/` | Skeleton (`pytest.fail`) |

### 1.2 검사 순서 (FR-01 §8.5)

`null` → `size` → 빈칸 개수 → 값 범위 → 중복  
AC-FR-01-01 Full RED 12건 = **`null` + `size` 거부**만.
