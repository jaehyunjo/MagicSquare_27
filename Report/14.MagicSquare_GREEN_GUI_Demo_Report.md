## 2. 상태 모델 (답안 vs Verify)

| 상태 | 의미 | FAIL? |
|------|------|-------|
| **idle** | 초기/초기화 | — |
| **unverified** | 답안 적용됨, Verify 전 | **아니오** (미검증) |
| **verified** | Verify 성공 | 성공 |
| **failed** | Verify 실패 또는 답안 탐색 실패 | 예 |

> **답안 버튼 직후** 결과 문구: `답안: APPLIED (미검증)` — FAIL이 아니다.  
> PASS/FAIL 판정은 **Verify**에서만 수행한다.

### 권장 흐름

```text
격자 입력 (빈칸 2개) → 답안 (미검증) → Verify (SUCCESS / FAILED)
```
