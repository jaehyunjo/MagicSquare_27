## 2. Objective & Scope

**목적**

- §8.5 검사 순서의 **1단계(입력 형식·차원·완전성, I-7)** 에서, 격자 참조가 없거나 canonical 16튜플이 성립하지 않는 입력이 **도메인 불변량(I-1~I-3) 진입 전**에 거부됨을 증명한다.
- ST-01 계약에 따라 Boundary·Control 경로 모두에서 **`InputError` + `INPUT_DIMENSION_MISMATCH`** 가 일관되며, Entity의 I-1 multiset·I-2/I-3 선 합 검사가 **호출되지 않음**을 증명한다.

**In scope**

- Boundary: 외부/raw 입력 → canonical grid 변환 시도, 차원·길이 0 거부, `InputError` 구조화(또는 동등 예외).
- Control: Profile `MS4X4_STD_V1` 로드, 검사 순서 준수, `VerdictResult` 조립, 입력 오류 시 조기 종료.
- 출력 계약: `verdict`, `violations`, `magicConstantExpected`, `profileId` (PRD §8.2).

**Out of scope**

- I-1 multiset, I-2/I-3 선 합, `Valid`/`Invalid` 판정, 마방진 생성, UI/CLI/HTTP 세부.
- 앵커 외 입력 오류 TC: **TC-008**(3×3), **TC-009**(4×4 내 null), **TC-010**(비정수), **TC-016**(4×5) — 후속 플랜에서 동일 패턴으로 확장.
- 결정성 전용 검증(**TC-017**)은 S4 후속 1건으로만 연계한다.

**Arrange 공통 (Domain 호출 관찰)**

- **Boundary 단위**: Entity의 I-1/I-2 규칙 또는 Control 내부 호출 지점에 **테스트 더블(스텁/스파이)** 주입. Act 전후 호출 카운트 **0 유지** 검증.
- **Control 통합**: **I-1/I-2 규칙 포트(가칭)** 스텁 `was_called == false` 검증.
- S0 `red` 초기: 의도적 실패(모듈 미존재·NotImplemented)도 RED 합격; 스텁으로 우회 통과는 금지.

## 4. Test Cases (앵커 + 레이어별 분해)

**Variant 통합 정책**: V-01·V-02는 Boundary RED **1개 테스트**로 파라미터화. V-03은 문자열 어댑터 존재 시 추가.

### 4.1 Boundary — Unit (RED 우선)

| Field | Content |
|-------|---------|
| **Test ID** | `test_tc011_empty_or_null_grid_rejected` |
| **Layer** | Boundary |
| **Arrange** | I-1/I-2 더블 호출 카운트 0. V-01: `raw_grid=None`. V-02: `raw_grid=[]` 또는 `()`. |
| **Act** | `parse_grid_input` / `to_canonical_grid` (가칭) |
| **Assert** | `InputError`; `violations[0].code == INPUT_DIMENSION_MISMATCH`; canonical 16튜플 미생성; I-1/I-2 호출 0 |
| **Negative assert** | `Valid`/`Invalid` 없음; `I1_*`/`I2_*`/`INCOMPLETE_GRID`/`INPUT_NON_INTEGER` 없음 |

### 4.2 Control — Integration (RED 2차)

| Field | Content |
|-------|---------|
| **Test ID** | `test_tc011_orchestrator_rejects_empty_grid` |
| **Layer** | Control (+ Boundary 어댑터 경유) |
| **Arrange** | `MS4X4_STD_V1` Profile; I-1·I-2 스텁 `was_called=False`; Given V-02 `[]` |
| **Act** | `verify_magic_square` (가칭) |
| **Assert** | `verdict == InputError`; `INPUT_DIMENSION_MISMATCH`; `profileId == MS4X4_STD_V1`; `magicConstantExpected == 34`; I-1/I-2 미호출 |
| **Determinism** | TC-017은 S4 후속 플랜 |

### 4.3 Entity — Explicit Non-Test

- TC-011은 구조·차원 위반으로 canonical `Grid`가 없어 Entity 규칙 단위 테스트 대상이 아니다.
- 차원·완전성은 Boundary 책임; Entity는 I/O·pytest 없이 순수 규칙만 담당한다.
